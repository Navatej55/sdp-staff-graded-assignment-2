GIT COMMANDS USED IN THIS ASSIGNMENT

1. git init
   Initializes a new Git repository in the current project folder.

2. git --version
   Displays the installed Git version.

3. git branch -M main
   Renames the default branch to main.

4. git status
   Displays the current state of the working directory.

5. git add index.html about.html
   Stages the initial HTML files for committing.

6. git commit -m "Initial project setup"
   Creates the initial commit.

7. git add index.html
   Stages the modified homepage.

8. git commit -m "Update homepage content"
   Records the homepage changes.

9. git branch feature
   Creates a new branch named feature.

10. git switch feature
    Switches to the feature branch.

11. git add about.html
    Stages changes made to about.html.

12. git commit -m "Add feature branch content"
    Commits the changes on the feature branch.

13. git switch main
    Switches back to the main branch.

14. git merge feature
    Merges the feature branch into main.

15. git branch
    Displays the local branches.

16. git log --oneline
    Displays the commit history in a compact format.

17. git log --oneline --graph --decorate --all
    Displays the commit history of all branches in graph format.

18. git status --ignored
    Displays ignored files and folders.

19. git add .gitignore
    Stages the .gitignore file.

20. git commit -m "Add gitignore for logs and temp files"
    Commits the .gitignore configuration.

21. git log --oneline -3
    Displays the latest three commits.

22. git revert HEAD --no-edit
    Reverses the latest commit by creating a new revert commit.

23. git log --oneline -5
    Displays the latest five commits.

24. git remote add origin "https://github.com/Navatej55/sdp-staff-graded-assignment-2.git"
    Connects the local repository to GitHub.

25. git remote -v
    Displays the configured remote repository URLs.

26. git push -u origin main
    Pushes the main branch to GitHub.

27. git push -u origin feature
    Pushes the feature branch to GitHub.

28. git branch -a
    Displays all local and remote branches.
